# Lawson Road church of Christ — social media library

Public image and video files for the Lawson Road church of Christ social
media posts. These files appear on our public Facebook page; this
repository is simply where they live so our posting scheduler can fetch
them.

- `batches/<week>/` holds the media for one week of posts, named for the
  Monday of that week (e.g. `batches/2026-09-21/`).
- Folders are pruned automatically a few weeks after their posts publish —
  the platforms keep their own copies, so the source files are no longer
  needed.

Nothing here is secret. The captions, schedule, and automation live in a
separate private repository.
